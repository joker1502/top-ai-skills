Midjourney is an AI image generation tool renowned for its artistic quality and distinctive visual style.

## Key Features

- High-quality image generation
- Style customization
- Upscaling and variations
- Discord-based interface

## Usage

Access Midjourney through Discord:

```bash
# In any Discord channel with Midjourney bot
/imagine prompt: a serene mountain landscape --ar 16:9 --v 6
```

## Parameters

```yaml
# Midjourney parameters
prompt: "a serene mountain landscape"
aspect_ratio: "16:9"    # --ar
version: 6               # --v
stylize: 250             # --s
chaos: 20                # --c
```
