## What It Is

A skill that pipes 50+ image generation models into your AI coding assistant. Instead of switching to a separate app or website for image generation, you type a prompt in Claude Code or Cursor and get back an image from FLUX, Gemini, Reve, or any model you choose. The inference.sh backend handles the API routing.

## What's Actually Different

Most image generation tools require their own interface — Midjourney in Discord, DALL-E in ChatGPT, or a dedicated web app. This skill collapses that into the same chat where you write code. The real difference is iteration speed: you can generate an image, discuss changes with your AI, and regenerate in the same conversation thread. Compared to manually copying prompts between tools, it saves the context-switch overhead that kills flow state.

## Who It's For

Worth installing if you regularly create images during coding — UI mockups, concept art for games, social media assets, or documentation illustrations. It replaces the friction of tabbing out to another service. Skip it if you only generate images once a month or need the controlled workflow of a dedicated tool like Midjourney or Photoshop's generative fill.

## Bottom Line

Image generation inside your coding environment, 50 models, one install.
