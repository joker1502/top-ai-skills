Cursor is an AI-first code editor that brings powerful AI capabilities directly into your development workflow.

## Key Features

- AI-powered code completion
- Multi-file editing with AI
- Chat with your codebase
- Agent mode for autonomous tasks

## Usage

Download from [cursor.com](https://cursor.com) and open your project:

```bash
# Open a project in Cursor
cursor my-project
```

## Configuration

```json
{
  "cursor.chat.context": "full",
  "cursor.generatedCode.enabled": true,
  "cursor.cpp.enabled": true
}
```
