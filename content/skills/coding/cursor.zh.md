Cursor 是一款 AI 优先的代码编辑器，将强大的 AI 能力直接融入你的开发工作流。

## 核心特性

- AI 驱动的代码补全
- AI 辅助多文件编辑
- 与代码库对话
- 自主任务代理模式

## 使用方法

从 [cursor.com](https://cursor.com) 下载并打开你的项目：

```bash
cursor my-project
```

## 配置

```json
{
  "cursor.chat.context": "full",
  "cursor.generatedCode.enabled": true,
  "cursor.cpp.enabled": true
}
```
