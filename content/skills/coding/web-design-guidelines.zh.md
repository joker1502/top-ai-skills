## 它能做什么

Web Design Guidelines 把 Vercel 工程团队的 Web 设计经验封装成 AI 代理可以遵循的规范——从布局和排版到色彩系统，从响应式断点到性能优化，覆盖一个现代化 Web 应用应该有的设计质量基线。Vercel Labs 出品（agent-skills 仓库，27k Stars）。

## 它与众不同在哪

大多数"AI 生成前端页面"的问题不是功能不对，而是设计质量差——间距乱、层级不清、颜色用得随心所欲。Web Design Guidelines 不教 AI 生成代码，而是教 AI 在设计阶段就遵循约束。它的特殊之处在于来源——Vercel 团队见过太多不同质量的 Next.js 项目，他们把这些经验提炼成了可执行的规则。跟 Tailwind 的 utility-first 理念配合得特别好，但即使你不用 Tailwind，里面的设计原则（排版节奏、留白体系、色彩对比度）也是通用的。

## 谁不适合用它

如果你已经在团队里有成熟的设计系统和 UI 规范，这个技能提供的原则你的设计系统已经覆盖了。它最适合的是那些没有专职设计师、靠 AI 做前端的个人开发者或小团队——给你一个"看起来不是业余作品"的最低保障。

## 总结

Web Design Guidelines 让 AI 生成的页面不只是功能完整——至少在视觉上不会让人觉得这是个业余作品。
