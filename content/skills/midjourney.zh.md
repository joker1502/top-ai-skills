Midjourney 是一款以艺术质量和独特视觉风格著称的 AI 图像生成工具。

## 核心特性

- 高质量图像生成
- 风格自定义
- 放大与变体
- 基于 Discord 的界面

## 使用方法

通过 Discord 访问：

```bash
/imagine prompt: 宁静的山脉景观 --ar 16:9 --v 6
```

## 参数

```yaml
prompt: "宁静的山脉景观"
aspect_ratio: "16:9"
version: 6
stylize: 250
chaos: 20
```
