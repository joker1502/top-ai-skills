## 它能做什么

让 AI 编程助手用「穴居人风格」回复——删掉所有废话，只留核心技术内容。平均减少 75% 的输出 token，速度提升约 3 倍。四个压缩级别可选，从轻量去填充词到电报式极简表达。还有记忆文件压缩功能，能重写 CLAUDE.md 等文件，平均减少 46% 的输入 token。

## 跟同类产品有什么区别

市面上没有直接竞品——大多数人的做法是在 system prompt 里加一句「be concise」，但模型经常不听。Caveman 是作为 Skill 安装的，直接控制 AI 的输出风格，效果硬性保证。还有一个独特功能是 `/caveman-stats`，实时显示省了多少 token 和多少钱。

## 哪些人适合用

用 Claude Code 或类似工具做日常开发的程序员。如果你每次等 AI 回复都觉得「说得太长了」，装一个试试。重度用户还能配合 caveman-shrink（MCP 中间件）压缩工具描述，配合 cavecrew 子代理减少子任务 token 消耗。

## 一句话总结

AI 的脑力不变，嘴巴变小，每次回复省 75% 的废话。
