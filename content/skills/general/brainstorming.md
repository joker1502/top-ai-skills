## What It Is + Verdict

Brainstorming is Obra's pre-implementation thinking skill. Before Claude writes a single line of code, this skill forces a structured exploration of user intent, requirements, and design alternatives. It is the most valuable skill to keep active permanently.

## The One Thing That Matters

The skill intercepts requests before implementation begins. When you ask Claude to build something, Brainstorming kicks in and runs a design thinking process: purpose, audience, constraints, differentiation. It makes Claude ask clarifying questions and explore alternatives before committing to a direction. This prevents the most common failure mode of AI coding — building the wrong thing well.

## What's Actually Different

Most skills trigger on domain-specific tasks. Brainstorming triggers on any creative or development request. It sits above domain skills, acting as a thinking layer that runs before any implementation skill activates. It pairs naturally with systematic-debugging on the other end of the workflow: plan first, verify after.

## Who It's For

Every Claude Code user should have this installed. It is most valuable for complex or ambiguous requests where the requirements are not fully specified upfront. Less useful for trivial, well-defined tasks like 'add a button' where the intent is already clear.

## Bottom Line

Brainstorming prevents Claude from building the wrong thing by making it think before it codes.
