## 它能做什么

Skill Creator 是 Anthropic 官方提供的"写技能的技能"。它教你如何设计、编写和改进 AI 代理 Skill——从目录结构到提示词策略，从工具声明到错误处理，覆盖了一个高质量 Skill 的完整生命周期。来自 anthropics/skills 仓库（144k Stars），是目前引用最多的 Skill 开发参考。

## 它与众不同在哪

这不是一个"帮你写代码"的技能，而是一个"教你怎么写技能"的元技能。市面上能找到大量 Agent Skill 的使用教程，但几乎没人告诉你如何创作一个质量过关的 Skill 包。Skill Creator 填补了这个空白——它有一套经过验证的模板和评审标准，让你写出来的 Skill 不会出现常识性错误（比如忘声明依赖、上下文泄露、提示词写得像命令而不是协作）。

## 谁不适合用它

如果你只是安装别人写好的 Skill 来用，不需要碰这个。如果你已经写过十几个 Skill，对格式和模式很熟悉了，也基本不需要它。Skill Creator 的目标受众是刚开始写 Skill 的人——那些"想贡献但不知道从何下手"的开发者。

## 总结

Skill Creator 是 Agent Skill 生态的"创作者入门手册"——有了它，你不再只是使用者，而是能贡献自己 Skill 的参与者。
